# 摘要与引言修订回应

日期：2026-09-23。基础版本：f8577e2（BioCoLoop 更名版）。本次仅调整写作与同步阅读副本，不新增或修改实验。

## 1. 摘要中的训练分配消融统计

采纳。删除摘要中“four held-out wins, eight ties ... 10.84-point ...”整句。它属于固定候选集、相同数据与算力下的训练预算分配消融，需要先解释 uniform allocation 与 screening/promotion 的对照，放在摘要中容易被当作整个 agentic loop 的总体收益。数值及统计区间继续保留于 Results 5.2 和对应表格。

摘要改为说明：三类生物任务、十实验室完整系统对单实验室 fixed-model/direct-optimization 参照，以及五个评估端点中的四个最高。这里明确了数据访问差异，不把主表描述成相同数据预算的比较。

## 2. 背景的单一主线

采纳关于场景混杂的意见，但保留数据共享约束这一研究动机。核心场景是：同一任务的多个实验室保留各自数据，同时让这些数据支持预测器训练和下一轮模型设计。隐私/共享约束是场景条件；跨实验室的持续模型改进是研究问题。

三类任务各有任务预测器，共享训练与研究接口；不是把 DTI、蛋白组和细胞数据混合训练一个统一大模型。引言明确加入“Each task uses its own predictor ...”。

## 3. 设计定义与理由

采纳。用主动定义“We define an executable design ...”代替“In our implementation ...”。范围明确为可训练预测组件与学习率、正则化、聚合设置；prediction components 同时覆盖预测头与残差适配组件。

理由是：这些选择能调整预测器的学习方式，同时维持生物任务和实验室本地训练接口一致。保持明确设计空间是统一执行与比较的设计选择，不是旁观式实现说明。

## 4. 第三项贡献

采纳。改为直说研究了什么：
- 三类任务上的共同框架；
- 对照区分实验室参与、proposal 反馈、训练预算分配；
- 分析研究模型、实验室数、独立数据来源、研究迭代次数。

删除重复的“The contribution is this coupling ...”结尾。不把设计反馈和预算分配混为一种效果，也不声称反馈在全部任务上都提升分数。

\subsection*{C.1 Shared biological task interface}
We connect the released research controllers of AI-Scientist-v2 \citep{Yamada2025AIScientistV2} and AI-Researcher \citep{Tang2025AIResearcher} to the same biological fitting and evaluation service used by BioCoLoop. The source versions are \texttt{96bd51617cfd} and \texttt{f9a6f8480860}, respectively \citep{AIScientistV2Code,AIResearcherCode}. Each public controller accesses ten laboratories, the original twelve-design library and six global proposal slots. The service first fits D00 afresh and then trains each valid new candidate for 100 rounds from the task/seed initialization. Repeated or invalid design requests consume a proposal slot. Development score and loss select the retained checkpoint under the original selection rule.

AI-Scientist-v2 retains its experiment manager, tree-search paths, experiment reviews and journal. AI-Researcher retains its native idea selection, planning, implementation, review handoffs and iterative experiment analysis. Task-specific prompts direct these controllers to the registered design interface. Executing arbitrary generated code, external retrieval, figure review and manuscript generation are outside this fixed-task experiment. The public controllers use local Qwen2.5-7B-Instruct with temperature 0.7, top-$p$ 0.9 and at most 512 generated tokens per call. Their adapter allows at most 160 model calls and 28,000 input tokens per call. Full model-call counts and token usage accompany each run; equal proposal and candidate-training budgets do not imply equal language-model costs.

\subsection*{C.2 Prediction quality and execution outcomes}
A scored run completes its research budget, seals development selection and passes independent rescoring of saved held-out predictions. A failed run receives an explicit outcome label, not a zero predictive score. Context failure denotes exceeding the declared input-token allowance; tool failure denotes exhausting three attempts to produce a valid call under the text-tool protocol; pipeline failure denotes an unresolved required native stage. These outcomes describe the executed controller, backend and task adaptation together. Source-integrity or training-infrastructure errors remain separately unresolved rather than being counted as method failures.

The public controllers use a recorded text-tool bridge. For example, a terminal call that names an available tool but uses an unsupported argument envelope can end with tool failure. This identifies an interface-compatibility outcome, whereas context failure identifies a resource-bound outcome. The original raw calls, failed attempts, native stage history and consumed proposal slots are retained. Pending cells denote runs that have not yet reached a verified terminal outcome.

\paragraph{Aggregation and scope.}
Held-out evaluation uses the previously registered test sets; these comparisons are retrospective rather than a new blind confirmation.
The single-seed table compares seed 42 for every method. The main table reports a three-seed mean and sample SD only when all of seeds 42--44 have valid scores; otherwise the cell reports its completion state. Failed runs are neither replaced by partially selected checkpoints nor averaged as zeros. Completion summaries retain the full registered denominator and distinguish verified scores, verified controller failures and pending work. The comparison evaluates the specified biological task adaptations of the public controllers.

\subsection*{C.3 Task-transport repair}
We additionally test a versioned AI-Researcher adaptation that removes repeated task packets from stage prompts while retaining the complete current task and measured evidence in each system prompt. Native stage reasoning and tool results are preserved. The text bridge also accepts an unambiguous \texttt{parameters} alias for \texttt{arguments}. Model weights, context allowance, proposal slots, candidate training and scoring remain unchanged. Fresh seed-42 runs on the four shorter endpoints test this repair separately from the original execution outcomes.

\section*{4. Experimental design}
We separate three questions: whether a better executable predictor transfers to held-out examples; whether access to additional local training data helps; and whether iterative research improves over direct generation with the same access. All arms within each task use the same unchanged scorer. Different task metrics are not averaged into an overall score.

\subsection*{4.1 Drug--target interaction prediction}
The DTI task predicts binary BindingDB interactions on the original DrugEvolve random, unseen-drug and unseen-protein test splits, containing 5,505, 3,791 and 2,507 pairs. Coldness is exact drug/protein-string identity, not scaffold or sequence-homology separation. We pin DrugBAN and DrugEvolve to their released implementations.

\paragraph{Full-training architecture transfer.}
Five historical campaigns per controller compare direct generation, native DrugEvolve and our production loop from the same DrugBAN source. Search has three candidate opportunities, a 24-call ceiling and four fits including baseline; its 2,048-row training pool and three-epoch recipe are unchanged. We transfer \emph{all fifteen} selected sources to the full-training evaluation, not a subset chosen by historical test results. Fixed DrugBAN and released DrugBAN-Evo complete the five-method roster.

Each method is trained on all 50,149 original training pairs for 100 epochs, with the same 5,604 validation pairs, batch size 64, Adam at $5\times10^{-5}$ and FP32. Paired fit seeds 342--346 share identical encoder/classifier initialization tensors. The earliest strict maximum validation AUROC selects the checkpoint after all 100 epochs. The 25 labels require 21 physical fits because four same-source/seed/recipe labels are explicit aliases; different seeds never share weights. TAPB \citep{lin2025tapb}, with frozen ESM2-650M protein features and its released task-training recipe, supplies a contemporary fixed predictive reference on the identical data. It is not a BAN-capacity-matched controller. Fixed cosine 5-NN uses the same full training pool. DTI evaluates predictive designs and research controllers, not federated training. Appendix L specifies all recipes, asset versions and checkpoint rules.

\paragraph{Fixed-predictor program research.}
A separate experiment asks whether source-level research can improve a deployed predictor without new weight fits. Both controllers receive the same completed DrugBAN fit (seed 342), cosine predictor and disclosed manual starting mixture $0.7p_{\rm BAN}+0.3p_{\rm cosine}$. Five trajectories per controller, indices 542--546, optimize a stateless probability-combination function. The common selector requires AUROC improvement above $10^{-4}$ on both compound-hash halves of the validation set (2,884/2,720 pairs). Three candidate opportunities and 24 model calls are common ceilings. All ten selections close before test scoring. These trajectories share one base-model fit; their SD is not training-seed uncertainty (Appendix M).

A frozen transfer test replaces DrugBAN probabilities with TAPB probabilities without changing any selected source bytes, the cosine input or the manual rule. Research indices 542--546 map one-to-one to TAPB fit seeds 342--346, identically for both controllers. All ten sources transfer with no new search, fitting or parameter selection. The mapping is declared before this extension reads TAPB test predictions, although some reference predictions already exist. This tests program portability, not research performed on TAPB.

\subsection*{4.2 Observed-response proteomics and local training}
The public ProteinTalks PTPC supplement \citep{Sun2026ProteinTalks} supplies measured 6h/24h proteomes and binary efficacy labels. The admitted data contain 979 conditions, 666 compounds and 5,171 proteins. Compound-grouped train/development/visible-gate/partner/final roles contain 491/96/90/154/148 conditions. The final role has 22 positives. This task classifies efficacy \emph{after observing} the two proteomic profiles; it does not forecast untreated-cell responses or reproduce the complete ProteinTalks model.

We cross direct generation and the native loop with one or ten training clients at five fixed compound partitions, 442--446: twenty campaigns. Each controller has the same rows within a client-count condition. One client contributes 44--59 training conditions; ten clients contribute all 491. The starting map normalizes the observed-protein and compound blocks locally, without pooled preprocessing statistics. Research changes only a row-wise NumPy feature map. All candidates use the same zero-initialized, $C=1$ logistic objective and distributed L-BFGS-B fitter described in Section 3. Clients execute actual local loss/gradient computations; their aggregate objective is numerically checked against centralized fitting.

Every campaign has three candidate opportunities, four fit attempts including baseline and 24 LLM calls. Retention requires both development and visible-gate AP to increase by more than $10^{-4}$. Direct proposals independently use the common baseline; loop proposals additionally inherit retained source and earlier accepted/rejected evidence. All twenty selections close before final scoring. Fixed logistic and same-pool cosine references separate data access from research organization. The partner role is unused. Appendix K gives the complete roster, failures, communication payloads and local-training equivalence check.

\paragraph{Training-CV-guided revision.}
The preceding selector sees only eight development and nine gate positives. A separately frozen revision uses compound-grouped three-fold CV within the original 491 training rows, covering 86 positives. Direct generation, our loop and native Helmsman each receive eight research trajectories, indexed 642--649, with the identical ten-client pool, fixed local-gradient fitter, baseline, agenda and selector. Retention requires improvement above $10^{-4}$ in both pooled out-of-fold AP and minimum-fold AP. Each trajectory permits three candidate opportunities, four CV evaluations including baseline and 24 LLM calls. Helmsman preserves its native stop at the first valid service execution; the external selector independently retains or discards that source, and unused budget is reported. All 24 selections close before full-training deployment fits and final scoring. Appendix O gives the native adaptation, fixed folds, implementation corrections, failures and exact-source deployment aliases.

\subsection*{4.3 Statistical scope and developmental studies}
Unseen-drug AUROC is primary for DTI; final AP is primary for proteomics. We retain secondary AUROC, AP, BCE, MCC where defined, and accuracy at the common fixed threshold 0.5. Predeclared paired controller contrasts use exact two-sided sign-flip tests and descriptive 10,000-draw paired bootstrap intervals; two-contrast families use Holm correction. Five-pair exact tests cannot attain $p<0.05$. Controller prompts and realized costs differ despite common ceilings; native implementations, not handwritten loop approximations, are executed.

These are disclosed developmental evaluations on public test roles that were previously exposed, with each new study's source selections closed before reuse. They are not newly blinded validation. Appendix N retains the complete earlier twelve-epoch DTI study, neural PTPC evidence-only factorial study, and exploratory Norman/GDSC-derived cell-policy tasks \citep{norman2019genetic,sung2026scdebart,yang2013gdsc}. Those studies diagnose task and controller behavior but are not substituted for the full-training or actual local-training comparisons.

\section*{3. Method: federated agentic biological research}
\subsection*{3.1 A shared inner trainer and outer research loop}
For design $a$, model parameters $w$, client datasets $D_i$ and participating laboratories $\mathcal K$, the framework alternates between
\[
 w_a^{\mathcal K}=\operatorname{FederatedFit}(a,\{D_i\}_{i\in\mathcal K}),
 \qquad
 a_{t+1}=\operatorname{Retain}(a_t,\widetilde a_t,E_t).
\]
Here $\widetilde a_t$ is a proposed executable design and $E_t$ is its aggregate development evidence. The inner process learns predictive parameters; the outer process tests changes to the predictor and its optimization. Every candidate restarts from the same task-specific initialization for its seed, rather than inheriting extra training from the incumbent. The language model itself is not fine-tuned.

\subsection*{3.2 Local parameter learning}
At round $r$, each participating laboratory receives shared parameters $w^r$ and completes one local epoch with AdamW. Local optimizer state resets each round, batch size is 64, and the gradient norm is clipped at one. With local fitted parameters $w_i^{r+1}$ and training-example counts $n_i$, the shared update is
\[
 \bar w^{r+1}=\sum_{i\in\mathcal K}\frac{n_i}{\sum_j n_j}w_i^{r+1},\quad
 v^{r+1}=\beta v^r+\bar w^{r+1}-w^r,\quad
 w^{r+1}=w^r+v^{r+1}.
\]
Setting $\beta=0$ gives sample-weighted FedAvg \citep{McMahan2017}. Momentum acts only on trainable parameters: floating model buffers are averaged and integer buffers use an elementwise maximum. This preserves nonnegative local BatchNorm variances instead of extrapolating them as parameters. A one-client run uses the same implementation with $|\mathcal K|=1$.

All candidates complete 100 rounds. Every five rounds, local development workers return scalar metrics; the coordinator retains the checkpoint with the highest equal-client mean primary metric, breaking ties by lower mean development loss. No test responses enter training, checkpoint selection or proposal generation. DTI trains the native DrugBAN network; proteomics trains an efficacy head; cell tasks adapt a frozen public scDEBART response head. Only these task adapters differ.

\subsection*{3.3 Evidence-guided design revision}
The shared research model is local Qwen2.5-7B-Instruct. A proposal contains a hypothesis, a planned experiment, an expected effect and a design identifier. The identifier compiles to an executable configuration from a common twelve-design library: learning rate, weight decay, server momentum and an optional zero-output-initialized width-32 residual adapter. The base predictor remains trainable. Appendix R lists the complete library. This unified study tests bounded design research, not arbitrary source editing; the earlier unrestricted source-search studies are retained separately.

Each direct or loop arm receives six proposal slots, with at most two generation attempts per slot for schema or novelty repair. Both share exactly the same first proposal. Thereafter direct search sees its tried configurations but no evaluation feedback; the loop sees the prior configurations, best development scores and rounds, first/last training and development diagnostics, and acceptance or failure records. These summaries let the proposer revise a hypothesis after underfitting, deteriorating validation or numerical failure without viewing biological rows.

Candidates are selected by the same primary-metric/loss ordering used for checkpoints. Rejected proposals remain in the history but do not replace the incumbent. A numerical failure consumes a slot and cannot promote an incomplete early checkpoint; its workers restart before subsequent trials. Infrastructure or contract errors halt the study instead of being scored as weak models. Identical configurations within the same seed and participation setting may reuse a completed fit across arms, while still consuming both logical proposal slots. Actual generation, fitting and communication costs remain separately recorded.

\subsection*{3.4 What laboratories contribute and what is shared}
During fitting, a laboratory worker reads its own response shard and returns model updates, counts and aggregate evaluation evidence. The research LLM receives the executable configuration and scalar history, not raw profiles, interaction rows or model-update arrays. The useful shared output is both a fitted predictor and a reproducible design that other compatible laboratories can execute. This is particularly relevant when additional biological measurements exist but cannot be centrally pooled.

The experiments simulate institutions on one host, with offline data packaging. They do not measure laboratory willingness to participate and do not provide differential privacy, secure aggregation or an adversarial isolation guarantee. Direct search can use the same local-training service; federation is not an ability exclusive to the agentic controller. The factorial comparison therefore tests the two components separately.

\section*{Reproducibility and responsible use}
The local reproducibility archive retains pinned source commits, original-scorer hashes, search/deployment contracts, campaign terminal receipts, budgets, selected source hashes, checkpoints, row-aligned predictions, metric recomputation, seed-level tables and failures. The public writing repository contains manuscript sources and aggregate tables, not those complete experimental artifacts or raw biological matrices; it must not be described as a standalone benchmark release. Source permissions and an anonymous, dependency-complete research artifact require separate review before submission. The final-test opening gate is a local manifest and procedural barrier, not cryptographic blinding against the machine owner. Model calls use a recorded text bridge; observed CLI tool execution fails the call. These are existing offline benchmarks, not prospective wet-lab or clinical validation. Predictions are not validated therapeutic advice.

\section*{AI use statement}
The evaluated research controllers use gpt-5.6-sol with ultra reasoning to generate candidate code and, where specified, hypotheses, repairs and analyses. Model-call receipts and failed invocations are recorded. AI coding assistants also assisted with task-adapter implementation, data-quality checks, analysis and visualization code, literature retrieval, manuscript drafting and editing. Reported experimental quantities come from executed scorers and traceable artifacts, not language-model estimates. Generated hypotheses and interpretations are distinguished from measured effects. No AI system is designated as an author.

\subsection*{5.3 Execution and model-selection evidence}
All branches share the proposer, design library, fitting schedule, aggregator and retention code. The paired first proposal is identical; subsequent direct proposals receive no evaluation history. Checkpoint seals, raw predictions and independent score recomputation connect reported values to executed runs. Model adapters and public pretraining provenance are versioned separately, so a simple efficacy head cannot silently inherit a ProteinTalks label or a target-trained checkpoint enter a one-laboratory baseline.

Synthetic regression tests are separate from scientific model selection. The earlier native DTI failure was traced to momentum on BatchNorm buffers; the common V3 trainer applies momentum only to parameters. Five response-free tests validate the cell attention-mask correction, including causal direction, padding exclusion, unchanged weights and BF16 execution. Every cell arm is rerun on corrected features. Any resulting improvement over the original implementation is a correctness effect, not a loop contribution.

\subsection*{5.4 Earlier task-aligned supporting experiments}
Historical full-training architecture transfer reached unseen-drug AUROC 0.9330 for loop-selected DrugBAN designs, versus 0.9239 for native DrugEvolve and 0.9280 for direct generation across five paired seeds (Appendix L). A stronger shared TAPB--retrieval design reached random/unseen-drug/unseen-protein AUROC 0.9710/0.9588/0.9317, with direct and loop tying from the same start (Appendix P). These studies support task-aligned model development but use different protocols; none fills a missing cell in the new uniform-protocol table.
